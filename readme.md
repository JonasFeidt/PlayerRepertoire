# PlayerRepertoire

A C++ application for generating player-specific opening repertoire trees from (multiple) PGN files.

## Features

- Import chess games from PGN files.
- Store games in a local SQLite database.
- Search games by player, color, and date.
- Generate opening repertoire from a player's games.
- Organize move sequences into a tree with main lines and variations.
- Export generated repertoires as PGN files.

## Technologies

- C++20
- Qt 6
- SQLite
- Disservin/chess-library
- CMake
